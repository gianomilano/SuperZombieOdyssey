# Super Zombie Odyssey Online

Zombie survival mod for Super Mario Odyssey. Rounds, perks, the Ray Gun, bosses, online co-op and a little secret hidden in the kingdoms.

You need Super Mario Odyssey 1.0.0 without the game update. Works on emulator (Ryujinx etc.) and on Switch with Atmosphère.

Download the zip from the releases page: https://github.com/gianomilano/SuperZombieOdyssey/releases/latest

How to install it is in the README.txt inside the zip.

To play online the host starts ZombieServer.exe from the zip and sends the join code to his friends. They jump into the Online painting in the start room and type it in. Only give the code to people you play with, it has your IP in it.

Updates: just run ZombieUpdater.exe, it only downloads what changed.

Have fun :)
